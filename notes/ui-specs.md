## 深海回响（v0.6.00 重写 / v0.6.01 修，权威）

`src/components/EchoView.vue`。语义是**奖励预览详情页**：左固定「万金之上」大图、
右固定其名称/类型/描述、底部 10 档轨道只是进度条。
**不做** UID、右缘翻页箭头、其余 9 档大图。

- 坐标：返回钮 66.5@(36.25,16.25) / 标题 119,34,31px / 缎带 279×44@(474.4,113) 非等比 /
  大图 1264×728@(93,51) / 物品名 200 宽@(1379,195) 43px / 饰线 521×140.4@(1240.2,188.1)
- ⚠️ `深海回想-UI坐标表.md` 描述的是**另一个界面**，勿用。
  权威基准：`布局坐标/深海回响/深海回响界面_实机UI坐标与动态效果分析.md`
- **四个关键坑（复用价值高）**：
  1. `track.webp` 512×512 波形振幅 99px，实机只有 43px → **不能等比缩放**；改 SVG 按 12 个实测点
     Catmull-Rom 插值画线（`TRACK_PTS`），素材只当 screen 柔光叠层且要 `scaleX(-1)`
  2. 光柱/摆饰大图素材都是**硬边矩形** → 必须 `mask-image` 双向羽化（`mask-composite: intersect`）
  3. `Teleport to="body"` 会脱离 `.design` 缩放 → 改 `position:absolute; inset:0; z-index:200`
  4. 档位多的池（遥远之海 36 档）会溢出 → `gap = min(169, 1734/(n-1))` + `--ck` 卡片等比缩
- 21 个素材归集为 `public/assets/ui/deepsea/*`（manifest `ui.deepsea`）
- 达成即已领取：无逐档详情页，`onMounted` 里把 `reached && !claimed` 全部 `claimMilestone()`

- **立绘层级**：`.sh-img` 在 `.sh-frame` **之前**（立绘在容器框之下，只在 collage 透明窗口处透出）
- **立绘背景图调色**（v0.9.09）：5★ 粉金 `sepia(.55) saturate(2.3) hue-rotate(-18deg) brightness(1.06)`；
  4★ 淡紫偏蓝 `sepia(.5) hue-rotate(205deg) saturate(1.55) brightness(1.04)`；其余浅冷调 `sepia(.35) hue-rotate(190deg) saturate(1.2) brightness(1.02)`
- **半身像比例**：试穿图 **520×724** vs 整体立绘 **448×656** → `isHalf` + `.sh-img.half{object-fit:cover}`
  单独比例充满窗口；**取不到试穿图时不得套用**（会裁掉整体立绘）
- **部件→试穿图匹配**：`partCard()` 两级匹配 —— ① 卡片名后缀 = 部件名；
  ② 兜底按部件 `slot`（= 卡片名前缀，全库 118 套**无重复**）。命中率 65.4% → **99.9%**
- **高亮框等大**：`itemEmpty`(160×160) 四周 3px 透明留白 → `.pt-hi` 用 `inset:-3px` +
  `calc(100% + 6px)`，蓝框正落在容器边界
- **雷达热区**：属性名位 `v.lx,v.ly`，**`r=20`**（v0.9.09 由 5 扩大；不是五边形尖角数据点 `v.x,v.y`）；数值显于 `v.ly-24`
- **星级间隔**（v0.9.09）：头部 60px 星 `margin-right -9.3 → -11`、部件 18px 星 `0 → -2.3px`（≈原 2/5 可见间隔）
- **头部结构**：`.in-namerow` = 名称 + `.in-tags`；`.in-stars` 是 `.in-head` 直接子级（在名称下方）；
  部件数 `.in-prog` 已移出标签行、改为信息区左下绝对定位
- **搜索**（v0.9.09 模板化）：抽出可复用 `src/components/SearchPopup.vue` + `src/core/museum-search.ts`
  （`PAGE_LABEL`：服装页/故事页/阅读页）。`.cl-swrap`/`.cl-sbg` 均 `pointer-events:none`，
  只有输入框/结果项/关闭键/跳转键 `pointer-events:auto` → 点任意空白都穿透到 `.cl-mask` 关闭。
  **主界面** `MuseumView.vue` 同时检索 服装/故事/阅读，同名用「｜」分隔（例 `小王子｜服装页`/`小王子｜故事页`/`《小王子日记的某页》｜阅读页`）；
  故事名(116)/阅读物名(593) 由 `tools/gen-museum-index.py` 生成 `src/data/museum-index.ts`；
  未来故事/阅读子界面沿用同一 `SearchPopup` 设计
