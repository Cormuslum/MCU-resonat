# 通用视觉坑清单（复用价值最高）

> 从 `MEMORY.md` 拆出（原文件过长导致注入截断）。规则性内容仍在 `MEMORY.md`。
> 每条都是**踩过且已修复**的坑，改 UI 前先扫一遍。

## 交互 / 命中区
- ⚠️ **`setPointerCapture` 会吃掉 `@click`**：`pointerdown` 里捕获后 `pointerup` 被容器接管 → 按钮 click 永不触发
  （用户报「切换键点了没反应」的真凶）。改法：**window 级 `pointermove`/`pointerup`(once)** + 位移 >5px 才算拖动，
  处理函数开头 `if (moved) return` 吃掉拖动那一下。
- ⚠️ **弹层空白退出区会被透明通道吞掉**：背景图整块是 `<img>` 时，四角 alpha=0 的透明像素**仍会命中元素** →
  点空白关不掉弹窗。改法：背景层与包裹层 `pointer-events:none`，只把**交互元素**（输入框/列表项/关闭键）恢复
  `pointer-events:auto`，空白点击即可穿透到遮罩触发 `@click.self`。
- ⚠️ **素材自带透明留白会让"等大"差一圈**：`itemEmpty`(160×160) 四周 3px 透明 → 直接 `inset:0` 铺满会显得**偏小**；
  要与容器等大就外扩留白：`inset:-3px` + `calc(100% + 6px)`。
- ⚠️ **两种比例的图不能共用一条 fit**：整体立绘 448×656 与试穿图 520×724 不同 → 半身像要单独 `object-fit:cover`；
  但**回退到立绘时不能套用**，否则立绘被裁 → 用「是否真的取到试穿图」判定，别用「是否选中部件」。
- 圆形按钮 95×96（back/close/skip），悬停态 `_h` **只有发光环无底**，需双 img 叠层。

## 混合 / 遮罩
- **`mix-blend-mode` 会被最近的层叠上下文隔离**：父级有 `z-index`/`transform`/`animation` 时 `screen` 只跟空上下文混
  → 黑底原样留下、光柱变实心矩形。
- 黑底白线素材（`ui/deepsea/track`、`ui/deepsea/arc*`、`ui.suit.glow*`）必须 `mix-blend-mode: screen`。
- 立绘白底不透明 → `multiply` 放浅色卡片上无缝融合。
- **Pillow 存的 lossy-alpha webp Chrome 解不出来**（PIL 能读、Chrome 报 decode 失败），`mask-image` 失败是**静默**的
  → 走 ffmpeg `-pix_fmt yuva420p`。
- 蒙版素材 alpha 峰值常只有 86~153 → `mask_webp()` 拉伸到 0..255；mask 挂 `::before`，否则文字被一起羽化。
- **装饰叠在羊皮纸上**：信息栏羊皮纸不透明会盖住同区域装饰 → 装饰要 `z-index` 抬高（配 `pointer-events:none`）。

## 渐变 / 尺寸
- **`radial-gradient(circle, …)` 的 100% 是 farthest-corner**（方形 84.85px ≠ 半宽 60）
  → 环带被推出元素外、整条弧静默消失，必须 `circle closest-side`。
- `aspect-ratio` + `grid-template-rows: 1fr` 循环依赖塌陷 → 卡牌用 `display:block`。
- 套装名条 332×96 空装饰条按原比例放，写死高度+cover 会裁掉左端花饰。
- **外发光会被 `overflow:hidden` 裁掉**（按钮宽 347 > pitch，容器为裁半截按键而 `overflow:hidden`）
  → 改用 `::after` 的 **inset box-shadow 蓝环**（叠在按钮图片之上，`0.4s` 呼吸 2px↔4px + opacity）。

## 色彩 / 状态
- 图鉴未获得：`grayscale(.6) brightness(.66) opacity(.55)`。
- 卡面/相框里的试穿图**不要加 scale**，只靠 `object-position`（`--oy`）。
- `bg1` 底部云海很亮，主页暗角单独压底部 0.72；主页装饰统一 `screen`；512px 星点群要平铺。
- **黑白↔彩色硬切要软边**：`clip-path: inset()` 是硬边 → 改 `mask-image: linear-gradient(...)`；
  ⚠️ 但**进度 0 时不能露彩色**：必须 `p<=0` 全透明、`p>=100` 全彩色、中间 `a=max(0,p-8) b=p`。
- **星级「可见间隔」要按透明留白反算**（star.webp 86×87，留白 L9/R10）：
  60px 星 `margin-right:-9.3px`、18px 星 `0`（均配 `gap:0`）→ 可见间隔 ≈4px。

## 方法论
- ⚠️ 按钮语义 class（`single`/`ten`）别删，巡检脚本靠它定位。
- **比对素材别「缩一半看」**，一律带缩放模板匹配（s=1.00/0.90/0.80 比 corr），
  否则会得出「需放大 1.28 倍」的错误结论。

## v1.3.00 新增（加载过渡 / 图鉴破碎 / 边缘唤起）

- ⚠️ **别给几百个碎片各挂 `filter`**：图鉴破碎第一版给 600 块各写 `filter: blur()/brightness()`，
  每块都会单独生成一个离屏渲染层 → 合成器直接崩，动画在 200ms 内被「跳完」（headless 里看着像没播）。
  改法：块上只跑 `transform/opacity`，亮度/迸光交给**整屏一层** `.mz-flash`。
- ⚠️ **Chrome 的 `filter: blur()` 会按元素边界裁切**：给 1080×559 的插画副本加大半径模糊做外发光，
  模糊结果被截在元素矩形里 → 边缘出现**直角亮块**。改用「更大尺寸的径向渐变雾团」+ 椭圆 mask，不靠 blur 外扩。
  同理，`mix-blend-mode: screen` 的雾也不要在元素上加 blur。
- ⚠️ **`img` 加载失败时只看 `naturalWidth === 0`**：dev server（sirv）**启动时**建立 public 文件索引，
  新增 `public/assets/ui/loading/` 这种新目录后 **必须重启 dev server**，否则返回 `index.html`（Content-Type: text/html）、
  浏览器 `complete: true` 但解码失败，页面只剩几个空框。
- ⚠️ **GIF 白底进深色页面必须抠**：`奔跑暖暖_动态.gif` 是不透明 `(254,254,254)` 底，
  直接转 webp 会是一块亮方形。抠白不要「删掉所有近白像素」（会把角色白裙打穿），
  用 `ImageDraw.floodfill` 从**八条边的种子点**做近白连通域填充，只吃背景。
- ⚠️ **「边缘 100px 唤起侧栏」不能只判坐标**：玄学收纳桶在 x≈19、共鸣卡池列表从 x=14 起，
  纯坐标判定会把它们的左半边永久挡住 → 追加「指针下的元素是交互元素 / 带 `data-no-rail` 就让位」。
- ⚠️ **整屏加载层默认拦截指针 1.4s**：巡检脚本里 `goto` 后的等待时间必须盖过它，
  否则悬停类断言全落空（`verify-almanac` 的 900ms → 1900ms）。
- 套名横幅「放大」要按**可见区**折算：素材 332×96 的实际底板只有 251×55，
  直接改盒子尺寸会「盒子变大了、眼睛看到的没变」。

## v1.3.01 新增（浅底图 / 音量链路 / 会话标记）

- ⚠️ **浅色底图上「纯白高亮」等于隐形**：加载层底图换成 `T_UI_loading_bg`（均值 RGB 223,226,220）后，
  进度条 `slider-on` 是 255 纯白，压上去完全看不见；off 态那条 125,151,136 也只有 98 的对比。
  任何「在深底上靠白色发光」的素材换到浅底都要重新算对比，必要时补一层局部暗化（取景框式渐变），
  而不是把素材调暗 —— 素材调暗会一起把 off 态压没。
- ⚠️ **水彩插画的白色羽化边要靠 `mix-blend-mode: multiply`**：带白边的水彩图叠在浅纸上，
  alpha 羽化只是「半透明白」，视觉上就是一圈方框。`multiply` 下白 = 不画，纸纹透出来，方框自动消失。
  同理 `screen` 的白雾在浅底上失效，要换成 `multiply` 的淡灰蓝才有「雾」。
- ⚠️ **音量链路里漏乘一层，症状会伪装成「只在某个界面生效」**：`bgmTarget` 少了 master 时，
  调零当场有效、一换界面 `startBgm` 重算回原值 —— 看起来像「只有当前页面生效」。
  正确做法是把所有系数收敛成**唯一一个 `level()`**，起播 / duck / 拉滑杆 / 切场景全部只认它。
- ⚠️ **`new Audio()` 的音量读不到**：`page.evaluate` 里 `querySelector` 找不到离屏音频元素。
  验收要读真实音量得用 `addInitScript` 包一层 `window.Audio`，把实例存进 `window.__audios` 再取最后一个。
  同时浏览器必须带 `--autoplay-policy=no-user-gesture-required`，否则 `play()` 被拦、`volume` 也没意义。
- ⚠️ **`v-if` 建出来的元素，`watch(computed)` 抓不到首帧**：`<video>` 由 `v-if` 创建时，
  watch 一个只在滑杆变化时才改的 computed 不会触发，元素就一直停在浏览器默认 `volume = 1.0`。
  要 `watch([elRef, volComputed], …, { immediate: true })` 才能「元素挂上就写一次」。
- ⚠️ **「压着按钮就让位」的侧栏规则会在整页按钮的界面上锁死导航**：版本页左栏从 x≈20 起全是版本卡，
  `x ≤ 100` 全程判给页面 → 侧栏永远够不到，而它是跨二级页跳转的唯一入口。
  留一条 32px 的**贴边死区**无条件展开，既保住导航，也只压住卡片最左 12px。
- ⚠️ **dev server 的静态索引不只看目录，新文件也要重启**：`public/assets/ui/loading/bg.webp` 加进**已存在**的目录，
  同样返回 `index.html`（200 + 469 字节）。判断方法：`curl -w "%{size_download}"` 看大小对不对。
- ⚠️ **Playwright 的 `page.$eval` 回调跑在浏览器里**：不能引用 Node 侧的函数（`ReferenceError: round is not defined`），
  要么在回调里算完再传出来，要么把工具函数挂在 `page.evaluate` 的参数上。
- ⚠️ **审计「首次进入」类标记时不要用业务字段兼职**：拿 `!profile.birth` 当「没问过」，
  用户点「不填写」后 birth 仍是 null → 每次进界都被当成首登重新盘问。要单独记一个 `asked` 标记，
  且**填写 / 跳过 / 清除**三条路都置位。
- 备份脚本必须**同名不覆盖**：`备份/` 里同一天同一版本号打两次包很常见（改前留基线、改完再打一次），
  直接 `ZipFile(w)` 会把基线悄悄覆盖掉（2026-11-01 就这样丢过一次）。

## v1.3.02 新增（抠白 / 音频循环 / 覆盖式写 manifest）

- ⚠️ **「把所有近白像素压成半透明」会打穿皮肤**：`奔跑暖暖.gif` 抠白后为了软化边缘，加了一句
  `r,g,b > 242 → alpha = 90`。卡通角色的**脸和手本来就是接近纯白的肤色**，一律被压成半透明，
  深色背景上一看就是「脸部是个洞」。正确做法不是调阈值（阈值再高也切不开肤色和纸白），
  而是**换一个本来就带 alpha 的素材**（`T_UI_loading_special_spirits.png` 的 16 格序列帧），一个像素都别动。
- ⚠️ **序列帧图集要先验帧序**：4×4 的 sheet 可能是行优先也可能是列优先，切错了动作会乱跳。
  用「相邻帧像素差」判定：行优先相邻差 8~14、首尾接缝 11.7（同量级）→ 顺序正确且循环闭合。
- ⚠️ **BGM 循环的「停顿」多半是源文件尾巴上的静音**：`silencedetect` 一量就见分晓
  （旧 wanzhang mp3：125.90 → 128.36 全是静音，每 2 分钟空一大拍）。
  换源后仍要用 `acrossfade` 把尾部 N 秒融进开头 N 秒，循环点才真正连续。
- ⚠️ **mp3 转 ogg 必须带 `-vn`**：带封面的 mp3 会把 mjpeg 封面转成一条 **theora 视频流**塞进 ogg，
  `ffprobe` 里就是 `theora + vorbis` 两条流。`<audio>` 虽然还能放，但白白多一条轨、多一层解析。
- ⚠️ **脚本写 manifest 一律 merge，不要整段赋值**：`man["ui"]["loading"] = {...}` 会把别人加的键
  （这次是 v1.3.01 的 `bg` 整屏底图）悄悄抹掉，而且不报错、只在界面上表现为「底图不见了」。
- ⚠️ **`:hover` 只能靠真实指针触发**：验收里 `dispatchEvent('mouseover')` 不会让 CSS `:hover` 生效，
  computed opacity 永远是 0。要用 `page.hover()`。
- ⚠️ **测「音量上限」不能取最后一个 Audio**：同一个音效在一页里会以不同 volume 播多次
  （主触发 0.85、叠加轻音 0.28），末次大概率是轻的那个。要包一层 `play()` 记录**每次播放瞬间的 volume**，
  再取最大值 —— 另外 `preloadAudio` 的预热元素从不 play，不记录就不会混进统计（它们的 volume 是 1）。
- ⚠️ **`net::ERR_ABORTED` 判 URL 后缀时别用 `$`**：`requestfailed` 的文本是
  `reqfail <url> net::ERR_ABORTED`，URL 后面还有字，`\.(webm|ogg)$` 永远不匹配，用 `\b`。
- ⚠️ **dist 里 `emptyOutDir` 被安全策略拦下时**，`vite build` 会在 `prepareOutDir` 阶段直接失败（且不改动 dist）。
  用 `npx vite build --emptyOutDir=false` 走增量覆盖即可，旧 hash 文件会残留但 `index.html` 只引用新的。

## v1.3.03 新增（音效定位 / 别名 / 一音多用）

- ⚠️ **「这个按钮响了哪一声」不要靠读代码猜**：同一界面里 `settings-open`（进页）、`panel-fadein`（弹面板）、
  `settings-btn-hover`（二次确认框）、`back-select`（关闭）四个音都在 500ms 内可能触发，光看调用点分不清。
  可靠做法：`addInitScript` 包一层 `window.Audio`，在 `play()` 里把 `{src, volume}` 压进数组，
  每做一次鼠标操作就 drain 一次 —— 得到的就是「这个动作实际响了什么」。
- ⚠️ **Wwise 事件名里的 `A;B` 是同一音频的多个别名，不是两段音**：`ui_general_window_a_open;ui_general_window_b_open`
  在 `索引.csv` 里是**同一行**（一个 mp3 文件 052_窗口打开.mp3）。想「A 和 B 一起播」的直觉是错的，
  按 `;` 拆开查表后两端会指向同一个文件，只会出一声。
- ⚠️ **一个音效被 21 处共用时，问题不是「音量太大」而是「所有弹窗一个味」**：`panel-fadein`
  （`UI_WBP_Resonance_RewarPanel_Fadein_Ten`，4.85s，本来是共鸣奖励面板专用）被复制到所有弹层，
  用户的第一反应往往是「这个音太响」，实际需求是「按场景换音」。遇到「某个音效听着不对」先数调用点，
  只有一个/两个才是调音量的问题，二三十个就该拆。
- ⚠️ **新 ogg 放进已有目录，dev server 依然不认**：`public/assets/sfx/` 里新增 6 个文件后，
  请求全部返回 200 + **469 字节 text/html**（sirv 的 fallback），必须重启 dev server。
  判断方法：`curl -w "%{http_code} %{size_download}"`，看大小是不是几百字节的 HTML。
- ⚠️ **转 audio 要用 merge 写 manifest**：`prep-sfx.py` 只 update `manifest.sfx` 的 6 个键，
  不要整体重建 —— 重建会丢 `banner-enter/*` 那 67 个卡池进入音。
- ⚠️ **改音效 key 要同步三处**：`.vue` 里的 `play('x')`、`useAudio.ts` 的 `SfxName` 联合类型、
  `collect-assets.py` 的 `SFX_EVENTS`。只改第一处能跑（`play` 接受 string），但下次重跑素材收集
  生成的 manifest 里就没有这个 key，表现为「静音 + 404」。

## v1.3.04 新增（ESC 返回栈 / 文案解析兜底 / SVG 高亮弧）

- ⚠️ **多个弹窗共用一个 `onKey` 时，最容易漏判的是「最后加的那个」**：`BannerView.onKey` 里
  `showEcho` / `showRules` 都判了，就 `showDetail` 没判 → 套装弹窗开着按 ESC 直接退回主页。
  加新弹层时**必须**同步补 ESC 分支，而且顺序要按层级从高到低（最上层最先 return）。
- ⚠️ **「跳转后按 ESC 能回来」不能用鼠标退出键走同一条路**：需求只让 ESC 回跳、点退出键走正常父级返回。
  做法是在 `goBack()`（点退出键那条）里 `clearHops()`，ESC 分支才 `takeHop()`。
  否则点了退出键之后栈里还留着一条，下次 ESC 会莫名其妙往回跳。
- ⚠️ **返回栈要存「URL」而不是「组件状态」**：来源页要恢复的东西（搜索弹窗开着、关键词是什么）
  全部编码进 query（`?resume=search&kw=xxx`），回来时由来源页自己 `onMounted` 还原。
  栈里只有一个字符串，不依赖任何组件实例，刷新也不会串。
- ⚠️ **素材 txt 的写法会有少数例外，解析器要留兜底**：套装文案段普遍是 `套装文案：\n『整体』……`，
  但 2.5 的《栖骨生花》是 `套装文案：` 之后**裸写正文**，没有 `『整体』` 标记。
  只按标记取会静默拿到空串，而界面上表现为「这套没有文案」 —— 不报错、只有看的人能发现。
  修法：进入该段后、第一个 `『部位』` 之前的裸文本，整段收作整体文案。
- ⚠️ **改完解析器要「扫全量」而不是只验那一条**：这次扫了 118 套，确认只有 1 套受影响；
  如果只验《栖骨生花》，根本不知道还有没有别的漏网（结果证明没有，但这是事后才知道的）。
- ⚠️ **SVG 曲线上画「已走过的部分」要和主线共用同一套几何**：
  直接对 path 改 `stroke-dasharray` 会踩到弧长不等分的坑；
  这里用同一个 `trackPath(x0, x1)` 从起点重画到当前抽数，几何天然贴合，不会错位。
- ⚠️ **验收脚本里造存档数据，顺序要和真实 `push()` 一致**：history 是追加存储（旧 → 新），
  造数据时若反过来写（新 → 旧），`slice(-50).reverse()` 的结果就会看着像「顺序错了」，
  实际是测试数据的锅。这种"看起来像 bug 的 bug"很费时间，造数据时先想清楚真实写入顺序。

## v1.3.05 新增（记录分池 / 随机池 / 硬编码总数）

- ⚠️ **「记录没持久化」经常是「按池过滤缺失」**：流水一直写在 `save.history` 里（刷新不丢），
  但读取时取的是全存档尾部 50 条 —— 换个池打开，看到的还是上一个池的记录，
  用户的第一反应是「记录没存」。排查顺序应该是：先看存档里有没有，再看读取有没有按归属过滤。
- ⚠️ **`slice(-N)` 这种「全局名额」在分桶数据上等于静默删除**：`writeSave` 原来 `history.slice(-500)`，
  抽得多的池会把别的池的流水整段挤掉，而且不报错、只是「老池记录突然空了」。
  分桶数据必须**逐桶截断**（`PER_BANNER`），再按时间重排。
- ⚠️ **奶白色图标压在浅色底上，调亮素材是反效果**：星级图标均值 RGB 227,205,175，纸底更浅，
  提亮只会更糊。正确做法是**给图标加深色衬底**（低透明度暖棕渐变 + inset 内阴影）
  + **给图标本身加描边**（两个方向的 `drop-shadow`），明暗边界来自衬底与描边，不是来自图标颜色。
- ⚠️ **「随机池」和「全部条目」必须分开表达**：彩蛋弹窗加了一批「不希望被随机抽到」的内容，
  若仍用 `Math.random() * EGG_ENTRIES.length`，新内容会立刻混进打开时的文案里。
  做法是数据层直接导出 `EGG_RANDOM_POOL`（合法下标数组），组件只认池子；
  翻页 / 页码跳转仍走 `0..N-1`，于是「能翻到但不能随机到」自然成立。
- ⚠️ **验收里别硬编码条目总数**：`/44`、`'24/44'` 这类断言在内容增长时必炸（这次 44 → 74 连炸三套脚本）。
  一律从 DOM 读 `total` 再比较，或者写成「序号 ∈ 1..total 且 total ≥ N」。
- ⚠️ **按归属过滤后，造测试数据要挂在「当前默认选中的桶」上**：`store.bannerId` 初值是
  `banner-2.10-02`，而 `manifest.banners[0]` 是 `banner-1.0-01` —— 往 `banners[0]` 灌流水，
  页面打开的却是另一个池，记录页直接空白（`verify-v2503` 这轮就是这么挂的）。

## v1.3.06 新增（媒体自动播放 / 分页行高）

- ⚠️ **「静音起步 + 等用户手势摘 muted」在 SPA 跨页时会失效**：手势监听器是在 HomeView `onMounted` 才注册的，
  而切回主页那次点击发生在**上一个页面**，注册晚于手势 → 视频静音播、直到下一次点击才出声。
  结论：**不要把声音挂在 `<video>` 上**。把音轨拆成独立 `<audio>` 后，回主页那次点击已经给 document
  留下了粘性激活，`play()` 直接放行；`<video>` 常驻 `muted` 还能保证它一定能自动播放。
- ⚠️ **粘性激活（sticky activation）是文档级的，不是元素级的**：同一次点击在 SPA 内换页后仍然有效，
  所以「切页面之后才创建的 audio 调 play()」是可以成功的 —— 前提是那一刻页面确实有过手势。
  只有冷启动直接落在该页（零手势）才会 reject，此时再挂一次性手势监听补放即可。
- ⚠️ **开屏动画自带声音时，主页音轨要等 `stage !== 'boot'`**：否则开场 5s 会有两条音轨叠在一起。
  验收里也不能死等固定毫秒，要 `waitForFunction(audio && !audio.paused)`，因为 boot 是否播过取决于会话标记。
- ⚠️ **拆音轨用 `-vn`，别把视频流一起带上**：`ffmpeg -i x.webm -vn -c:a libopus -b:a 96k out.ogg`
  → 1.35MB / 116.3s，与视频同长；`<audio loop>` 和 `<video loop>` 各自从 0 开始，天然同步。
- ⚠️ **固定行高 × 固定条数 = 显示整数像素**：10 行 × 34px = 340 > 列表可视 332px → 底部多出 8px 滚动条。
  行高收到 33px（330px）才严丝合缝。改「单页条数」或「面板高度」时必须重算这一条。
- ⚠️ **禁用态不要压太狠**：分页圆钮在首页时左键 `disabled`，`opacity: .32` 在白纸底上几乎看不见，
  用户会以为「这一页没有翻页键」。`.45` 左右既能表达禁用，又保得住形状。
