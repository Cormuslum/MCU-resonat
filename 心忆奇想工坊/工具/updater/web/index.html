怎么用

  1. 选一件事：左边挑「版本 / 服装阁 / 套装 / 故事 / 阅读物」。
  2. 填几个字：版本号、服装阁名、套装名 —— 只有这些没法从图里猜出来。
  3. 把素材拖进来：整套图可以直接从资源管理器拖到页面上；也可以把完整路径粘进「按路径读取」。
  4. 预检：看看必填项和缺图；写入并更新：读素材 → 跑管线 → 写进模拟器（写完回到模拟器刷新一下就能看到）。

写错了不要紧：每次写入都会存快照，右边「最近改动」里可以一键撤回。

扩展包（DLC）：左栏最后一项。更新做成一个自包含的包， 包自己声明提供哪些接口（服装阁 / 套装 / 故事 / 阅读物 / 版本）， 每个接口都能单独开关 —— 装上不挂载就完全不生效。顶栏的 上传 / 下载 用来把包发到云端、网盘或 git 仓库，或从那里取回来。
